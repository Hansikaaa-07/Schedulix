▤OS Lab Notes

Experiment write-up and reference material for CPU scheduling.

Aim

To simulate CPU scheduling algorithms FCFS, SJF and Round Robin, and calculate completion time, turnaround time, waiting time, CPU utilization and throughput.

Procedure

  1. Enter each process's arrival time and burst time.
  2. Select a scheduling algorithm and, for Round Robin, set a time quantum.
  3. Run the simulation and inspect the Gantt chart.
  4. Compare the calculated process metrics and execution log.

Pseudocode (Round Robin)

Initialize remaining burst for every process
Time = 0; ready queue = empty
While any process is unfinished:\tAdd arrived processes to ready queue
	If queue is empty: advance time to next arrival
	Else:\tRemove first process from queue
	Run it for min(quantum, remaining burst)
	Update time and remaining burst
	Add newly arrived processes
	If process unfinished: enqueue it again
	Else: record completion time
Calculate TAT = CT - AT
Calculate WT = TAT - BT

C Program (FCFS reference)

#include <stdio.h>
int main() {
 int n, i, at[20], bt[20], ct[20], tat[20], wt[20];
 printf("Enter number of processes: "); scanf("%d", &n);
 for(i=0;i<n;i++) {
  printf("Enter arrival and burst for P%d: ",i+1);
  scanf("%d%d",&at[i],&bt[i]);
 }
 // FCFS assumes input is sorted by arrival time
 int time=0;
 for(i=0;i<n;i++) {
  if(time<at[i]) time=at[i];
  time += bt[i]; ct[i]=time;
  tat[i]=ct[i]-at[i]; wt[i]=tat[i]-bt[i];
 }
 printf("PID CT TAT WT\\n");
 for(i=0;i<n;i++) printf("P%d %d %d %d\\n",i+1,ct[i],tat[i],wt[i]);
 return 0;
}
Reference implementation: sort processes by arrival time first if input is not ordered. The simulator itself handles unsorted entries.

Frequently Asked Questions

What is a time quantum?

Maximum CPU time a process receives in one Round Robin turn.

What is turnaround time?

Total time from arrival to completion (CT − AT).

What is waiting time?

Total time spent waiting in the ready queue (TAT − BT).

Which algorithm is preemptive?

Round Robin is preemptive. FCFS and this SJF implementation are non-preemptive.
